# @dashflowx/datagrid

Client data grid on `@dashflowx/core`. Table primitives live here; core re-exports `table`/`tr`/`th`/`td` as deprecated.

```bash
cd dashflow-datagrid
yarn install
yarn test
yarn storybook   # http://localhost:6008
```

No database. Free: sort, page, select, CSV. Pro (`@dashflowx/datagrid-pro`): virtual scroll, mock server, pin, inline edit.

Do not `npm publish` until X05 (G06).
